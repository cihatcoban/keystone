# LESSONS.md — what this project has learned the hard way

> Copy to the project root as `LESSONS.md`. Entries are added by `/retro` and
> merged only after review, like code. One lesson per `##` heading; the
> `session.handoff-load` hook tells each new session how many exist.
>
> A lesson earns a place when it changed, or should change, how the next person
> works here. A one-off fact belongs in the handoff note; a decision belongs in
> an ADR; a mechanical rule belongs in a check or a `.keystone/rules/` file —
> then delete the lesson that the check replaced.

- **Why it happened:** `<the cause, not the symptom>`

- **Enforced by:** `<check, rule or review item — or "review only">`
