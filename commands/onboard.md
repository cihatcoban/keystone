Apply `context-engineering`.

1. Discover the stack per `CLAUDE.md` §3 — run the commands, do not assume them.
2. Map the layout and the dependency direction between the main directories.
3. Identify conventions from the last 20 merged changes, not from preference.
4. Write or update the project profile; every command in it must have been run.
5. If `CONSTRAINTS.md` is missing, say so and offer `/constraints`.
6. Report: stack, commands verified, conventions found, landmines, and anything
   that looks like an undocumented decision worth an ADR.
